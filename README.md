# Дипломный проект: API-тестирование Stellar Burgers

## Структура проекта и описание файлов

### Архитектура и хелперы
`api.py` (`ApiRequests`) — класс-клиент API. Содержит статические методы для отправки HTTP-запросов (`GET`, `POST`, `DELETE`) на эндпоинты аутентификации, удаления пользователей, работы с ингредиентами и создания заказов.

`data.py` (`TestUrl`) — конфигурационный файл. Содержит класс URL-адресов со всеми необходимыми эндпоинтами (ручками) бэкенда Stellar Burgers для регистрации, логина, заказов и ингредиентов,
класс `TestData` со статичными данными.

`helpers.py` (`Helpers`) — вспомогательный класс. Хранит статические методы для генерации случайных текстовых строк и экспресс-генерации валидной полезной нагрузки (payload) для создания уникального пользователя.

`conftest.py` — глобальный файл конфигурации PyTest. Хранит фикстуры для генерации и предустановки тестовых данных (`Setup`), включая регистрацию тестовых пользователей с последующей автоматической очисткой данных через `yield`, возвращение заголовков авторизации с токенами (`accessToken`).

---

### Тестовые наборы (Test Suites)
`test_reg_user.py` (`TestRegisterUser`) — тесты ручки создания пользователя: успешная регистрация уникального аккаунта (200), обработка попытки создания дубликата существующего пользователя (403), а также параметризованная проверка валидации обязательных полей логина, пароля и имени (403).

`test_login_user.py` (`TestLogin`) — тесты ручки авторизации курьера/пользователя: успешный вход зарегистрированного пользователя с получением токенов (200) и параметризованная валидация обработки некорректных или несуществующих данных авторизации (401).

`test_order_create.py` (`TestOrder`) — набор тестов для проверки создания заказов. Включает сценарии успешного оформления заказа авторизованным (200) и неавторизованным пользователем (200), проверку запрета на отправку заказа без ингредиентов (400) и обработку сервером невалидных ID ингредиентов (500).

## Инструкция по запуску тестов

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python 3. Находясь в корневой директории проекта, установите все необходимые зависимости и внешние библиотеки одной командой:
```bash
pip install -r requirements.txt
```

### 2. Локальный запуск тестов
Для стандартного выполнения всех тестов, находясь в корневой папке, выполните команду:
```bash
python -m pytest tests/
```

Если вы хотите запустить тесты с явным указанием путей для стабильного импорта модулей без настройки системных путей, используйте модуль python:
```bash
python -m pytest tests/
```

## Генерация отчетов Allure

Все тестовые сценарии размечены аннотациями `@allure.suite`, `@allure.sub_suite`, `@allure.title` и `@allure.description` для создания наглядной документации в графическом интерфейсе.

1. Сбор результатов тестирования:
   Запустите тесты с указанием папки для сохранения результатов Allure командой:
   ```bash
   python -m pytest --alluredir=allure-results tests/
   ```

2. Просмотр графического отчета:
   Для генерации веб-интерфейса отчета и его автоматического открытия в браузере выполните команду:
   ```bash
   allure serve allure-results
   ```

3. Генерация статического отчета в текущую папку:
   Если вам требуется собрать постоянную папку с HTML-отчетом без запуска локального сервера, выполните:
   ```bash
   allure generate allure-results --clean -o allure-report
   ```
